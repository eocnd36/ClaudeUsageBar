따로 가입하거나 로그인할 필요가 없어요. 이미 쓰고 있는 Claude Code 로그인을 그대로 씁니다. There's no new account to create. The app uses the Claude Code login you already have.

  1. 앱 내려받기Download the app

    zip을 풀고 응용 프로그램 폴더로 옮기세요. 처음 열 때 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안에서 "그래도 열기"를 누르거나, 아래 명령을 실행하세요. Unzip it and move it to Applications. If macOS blocks the first launch, choose Open Anyway in System Settings → Privacy & Security, or run this command:

    xattr -dr com.apple.quarantine "/Applications/Claude Usage Bar.app"

  2. Claude Code에 로그인Sign in to Claude Code

    터미널에서 claude를 실행해 Pro · Max · Team 계정으로 로그인하세요. 이미 쓰고 있다면 건너뛰어도 됩니다. Run claude in Terminal and sign in with your Pro, Max or Team plan. Skip this if you already use Claude Code.

  3. 연결 누르기Press Connect

    메뉴 막대의 게이지를 클릭하고 연결을 누르면 끝이에요. 연결 해제도 설정에서 언제든 할 수 있습니다. Click the gauge in the menu bar and press Connect. You can disconnect anytime in Settings.

자주 묻는 질문Questions and answers

Claude 사용량(사용 한도)은 어떻게 확인하나요?

Claude Code에서 /usage 명령을 실행하거나 claude.ai 설정의 사용량 화면에서 볼 수 있습니다. Claude Usage Bar를 설치하면 현재 세션과 주간 한도 사용률이 macOS 메뉴 막대에 늘 표시되어, 따로 확인하러 가지 않아도 됩니다.

Claude의 5시간 한도는 언제 초기화되나요?

Claude 구독 플랜의 세션 한도는 5시간 단위로 초기화됩니다. Claude Usage Bar는 정확한 초기화 시각과 남은 시간을 보여 주고, 원하면 초기화 5분에서 60분 전에 알림을 보냅니다.

Claude 주간 한도는 무엇인가요?

세션 한도와 별도로 7일 단위로 적용되는 사용 한도입니다. 플랜에 따라 모든 모델 공통 한도 외에 Opus나 Sonnet 전용 주간 한도가 따로 있을 수 있으며, Claude Usage Bar는 계정에 적용되는 주간 한도를 모두 표시합니다.

claude.ai 웹과 데스크톱 앱 사용량도 포함되나요?

네. Claude 구독의 사용 한도는 claude.ai, Claude 데스크톱 앱, Claude Code가 함께 쓰기 때문에 Claude Usage Bar에 보이는 수치가 전체 사용량입니다. 이번 주 사용량이 어디서 나왔는지(Claude Code, 채팅, Cowork)도 비율로 보여 줍니다.

Claude Code 없이도 쓸 수 있나요?

아니요. Claude Usage Bar는 Claude Code에 저장된 로그인을 사용하므로, Claude 구독(Pro, Max, Team) 계정으로 Claude Code에 한 번 로그인해 두어야 합니다.

안전한가요? 내 계정 정보는 어디로 가나요?

로그인 토큰은 사용량을 불러올 때 Anthropic 서버(api.anthropic.com)에만 전송되고 다른 서버나 분석 도구는 쓰지 않습니다. Claude Code 로그인은 읽기만 하고 바꾸지 않으며, 소스 코드가 모두 GitHub에 공개되어 있습니다.

무료인가요? 어떤 Mac에서 쓸 수 있나요?

무료 오픈소스(MIT 라이선스)입니다. macOS 13 Ventura 이상에서 동작하며 Apple Silicon과 Intel Mac을 모두 지원합니다.

How do I check my Claude usage limits?

Run /usage in Claude Code, or open the usage page in claude.ai settings. With Claude Usage Bar installed, your current session and weekly limit usage stays visible in the macOS menu bar, so you never have to go looking.

When does Claude's 5-hour limit reset?

Session limits on Claude subscription plans reset in 5-hour windows. Claude Usage Bar shows the exact reset time and the time remaining, and can remind you 5 to 60 minutes before the reset.

What is Claude's weekly limit?

It's a usage limit applied over 7 days, separate from the session limit. Depending on your plan there may be a separate weekly limit for Opus or Sonnet in addition to the all-models limit. Claude Usage Bar shows every weekly limit that applies to your account.

Does it include usage from claude.ai and the desktop app?

Yes. Claude subscription limits are shared across claude.ai, the Claude desktop app and Claude Code, so the numbers in Claude Usage Bar are your total usage. It also shows where this week's usage came from: Claude Code, chat or Cowork.

Can I use it without Claude Code?

No. Claude Usage Bar uses the login saved by Claude Code, so you need to sign in to Claude Code once with a Claude Pro, Max or Team plan.

Is it safe? Where does my account data go?

Your login token is only sent to Anthropic (api.anthropic.com) to fetch usage. There are no other servers and no analytics. The app reads the Claude Code login without changing it, and all of the source code is public on GitHub.

Is it free? Which Macs does it support?

It's free and open source under the MIT License. It runs on macOS 13 Ventura or later, on both Apple silicon and Intel Macs.
